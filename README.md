# Автосервіс (autoservice)

**Практична робота №1**

**Дисципліна:** Об'єктно-орієнтоване проєктування

**Тема:** Об'єктно-орієнтований аналіз предметної області за допомогою ШІ-агентів з використанням UML-діаграм.

**Виконав:** Брикун Вадим Тарасович

## Опис проєкту

Навчальний проєкт інформаційної системи «Автосервіс».

Система передбачає:
- Онлайн-запис автомобіля на діагностику.
- Створення замовлення-наряду та кошторису.
- Облік виконаних робіт і використаних запчастин.
- Погодження власником додаткових ремонтних робіт.
